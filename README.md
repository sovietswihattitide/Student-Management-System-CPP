 Student Management System (C++)

A simple console-based Student Management System built with C++ as one of my early programming projects in 9th grade.

The project helped me practice the basics of C++, especially functions, vectors, user input, and organizing a program into separate parts.

 Features

- **Admin Login** — Password-based access to the main menu.
- **Add Students** — Enter student names and roll numbers.
- **View Student Records** — Display the students that have been added.
- **Vector-Based Storage** — Store student records using C++ vectors.
- **Function-Based Structure** — Keep different parts of the program organized using functions.

  Built With

- C++
- Standard Template Library (STL)
- `vector`
- Functions

 Getting Started

 Requirements

 C++ compiler, such as GCC, MinGW, or the compiler included with Code::Blocks or Dev-C++.

 Run the Project

1. Download or clone this repository.
2. Open `main.cpp` in your preferred C++ editor.
3. Compile the source file using your C++ compiler.
4. Run the compiled program in a terminal or console.
